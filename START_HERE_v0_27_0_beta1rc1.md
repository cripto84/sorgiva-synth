# Sorgiva Synth v0.27.0-beta1-rc1 — Avvio rapido

1. Estrai la cartella completa dell'archivio ESSENZIALE.
2. Avvia `index.html` in un browser Chromium desktop aggiornato. Per controller MIDI utilizzare `localhost` o `https`.
3. Abbassa il volume, premi **Sblocca Audio** e seleziona **Default Init**.
4. Apri **Performance → Adaptive Performance** e verifica il profilo **AUTO**.
5. Se non stai suonando, esegui facoltativamente il benchmark silenzioso.
6. Prova note singole, accordi, Sustain, Unison, Sequencer/Arp e Morph.
7. Per errori, segnala browser, sistema, preset, azione, tempo e se e presente MIDI fisico.

Versione candidata: i test automatizzati non certificano l'assenza di dropout reali.
Per tornare alla alpha17, tieni entrambi i pacchetti in cartelle separate.
